## About

I am a CS student interested in systems software, software quality, and practical AI.
I like building core components from first principles, then pushing them beyond demos with tests, CI, documentation, and real end-to-end workflows.

Current focus:

- Operating systems, runtimes, networking, databases, and compilers
- Software testing, mutation testing, fault analysis, and reliability
- Machine learning, computer vision, and AI-assisted engineering

## Featured Engineering

### [miniOS](https://github.com/Lei-TzuY/minios-x86)
A bootable 32-bit x86 operating system written from scratch in C and assembly.

- Ring-3 userspace, preemptive scheduling, fork/exec/wait, signals, IPC
- Copy-on-write fork, demand paging, mmap, shared memory
- VFS with RAMFS, ATA-backed DiskFS, FAT16, and `/proc`
- Native unit tests plus QEMU/GRUB end-to-end testing
- Ongoing mutation-testing and fault-driven hardening work

### [Mini Container Runtime](https://github.com/Lei-TzuY/mini-container-runtime)
An educational Linux container runtime in Go built directly on kernel primitives.

- Linux namespaces, cgroups v2, OverlayFS, veth networking
- OCI image pulling, port mapping, capabilities, seccomp
- Modular internal packages, automated tests, and GitHub Actions CI

### [Userspace TCP/IP Stack](https://github.com/Lei-TzuY/userspace-tcpip-stack)
A portable userspace TCP/IP stack and packet-analysis project in C.

- Protocol parsing and packet processing
- PCAP workflows
- Sanitizers and fuzzing-oriented validation

### [tinydb-c](https://github.com/Lei-TzuY/tinydb-c)
An educational relational database engine in C.

- B+ tree storage and indexing
- WAL recovery and transactions
- Query execution, secondary indexes, and inspection tooling

### [Tiny Transformer + Autograd](https://github.com/Lei-TzuY/tiny-transformer-autograd)
A from-scratch Transformer and automatic differentiation engine in Python.

- Custom reverse-mode autograd engine
- GPT/Llama-style Transformer building blocks from fundamentals
- Numerical, regression, and integration testing
