## `03 / engineering philosophy`

```text
$ cat principles.txt
→ build from first principles
→ prefer evidence over feature lists
→ test unhappy paths, not only demos
→ document limitations as seriously as capabilities
→ understand the layer below the abstraction
```

I am especially interested in **operating systems, runtimes, networking, storage, software quality and practical AI** — projects where correctness matters and the interesting work begins below the framework layer.
